# XenDrift

Enhances digital asset management for artists and designers by and storing project files across devices and platforms securely.

The key benefits of using XenDrift include:

- Enhances digital asset management for
- artists and designers by and
- storing project files across devices

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/XenDrift.git`
2. `cd XenDrift`
3. Install in editable mode: `pip install -e .`

## Configuration

XenDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
